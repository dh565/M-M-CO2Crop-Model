# M-M-CO2Crop-Model
M&amp;M-CO2Crop: mechanistic coupled carbon–nitrogen–water–energy crop models. First member: M&amp;M-CO2Wheat v1.0 (Helman, 2026, Geosci. Model Dev.); release archived at doi:10.5281/zenodo.23687586

# M&M-CO2Crop model family

Mechanistic, point-scale crop models in which carbon, nitrogen, water, and energy are solved as one coupled system.

## M&M-CO2Wheat v1.0 (release 1.0.0)

- Frozen publication package (source, input manual, decks, test case, figure scripts): https://doi.org/10.5281/zenodo.23687586
- Reference outputs of the 38 FACE simulations: https://doi.org/10.5281/zenodo.23688770
- WheatDryFACE observation tables used by the papers: https://doi.org/10.5281/zenodo.23688951
- Papers: Helman, D. (2026). M&M-CO2Wheat v1.0 — Part 1: Model description; Part 2: Model evaluation against three wheat FACE experiments. *Geoscientific Model Development* (submitted).

The release package will be mirrored in this repository as `MMCO2Wheat/v1.0/`. Licence: M&M-CO2Crop Research Licence v1.0 (see the LICENSE file in the package).

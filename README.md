# M-M-CO2Crop-Model

M&M-CO2Crop: mechanistic, point-scale crop models in which carbon, nitrogen, water and energy are solved as one coupled system. First member: M&M-CO2Wheat v1.0.

## M&M-CO2Wheat v1.0 (release 1.0.0)

- Code: folder `MMCO2Wheat/v1.0/` of this repository, tag `v1.0.0`. Archived publication package (source, input manual, decks, test case, figure and table scripts): https://doi.org/10.5281/zenodo.23687586
- Reference outputs of the 38 FACE simulations: https://doi.org/10.5281/zenodo.24373926
- WheatDryFACE observations (Helman and Mulero, 2026): WheatDryFACE free-air CO2 enrichment experiment, Israel, 2022/23–2024/25: processed observations in ICASA format, https://doi.org/10.5281/zenodo.24352317; WheatDryFACE free-air CO2 enrichment experiment, Israel, 2022/23–2024/25: raw sensor and image data, https://doi.org/10.5281/zenodo.24352486; the tables in the layout read by `paper_scripts/`: https://doi.org/10.5281/zenodo.23688951
- Papers: Helman, D. (2026). M&M-CO2Wheat v1.0: A fully mechanistic coupled carbon–nitrogen–water–energy wheat model with a closed canopy energy balance — Part 1: Model description; and M&M-CO2Wheat v1.0 — Part 2: Model evaluation against three wheat free-air CO2 enrichment (FACE) experiments. Submitted to Geoscientific Model Development.
